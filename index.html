gha-ansible provides composite actions for building your own jobs and reusable workflows for common Ansible project automation. The combined workflow runs lint and tests by default; publishing and playbook execution are opt-in.

Browse the individual actions, see the combined workflow example, or learn about documentation and action versioning.
