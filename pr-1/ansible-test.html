Ansible test ​

The ansible-test action installs ansible-core and optional project dependencies, installs Galaxy requirements, checks playbook syntax, and can run Molecule. Leave playbook empty to skip syntax checking. Molecule and its driver can be installed from your requirements_file.

yaml
steps:
  - uses: actions/checkout@v4
  - uses: ssongin/gha-ansible/.github/actions/ansible-test@master
    with:
      working_directory: ansible
      galaxy_requirements_file: collections/requirements.yml
      playbook: site.yml
      molecule: true
      molecule_directory: ansible/roles/web

Use the reusable workflow when you want a ready-made GitHub Actions job:

yaml
jobs:
  test:
    permissions:
      contents: read
    uses: ssongin/gha-ansible/.github/workflows/ansible-test.yml@master
    with:
      working_directory: ansible
      galaxy_requirements_file: collections/requirements.yml
      molecule: true
